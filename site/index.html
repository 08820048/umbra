01 · 能力

页面上能做的事

  1. 划词翻译选中后出现

    选中网页文字后出现「翻译」。这段文字若已是目标语言，按钮停用，请求也不发出。

  2. 全文翻译可恢复原文

    从弹窗或右键菜单开始。翻译整页，或把页面恢复成原文。

  3. 自带密钥兼容 Chat Completions

    在选项页填写 Base URL、密钥和模型。内置常用接口预设，也可自填地址。

  4. 流式输出边到边显示

    偏好页上有目标语言、划词即译、流式输出。打开后，译文随接口返回逐段出现。关掉，则等完整结果再显示。

02 · 边界

文本怎么离开浏览器

  1. 1 密钥留在本机设置写在 chrome.storage.local。作者收不到密钥、选中文本或译文。
  2. 2 只在翻译时送出打开网页不会上传正文。你点翻译，或打开「选中立即翻译」，文本才发往你填的接口。
  3. 3 接口由你填写请求走 OpenAI 兼容的 /chat/completions。Ollama 默认连本机。
  4. 4 同语言不再请求选中文本若已属目标语言，划词即译会跳过。

04 · 问题

常见问题

它和浏览器自带翻译有什么不同？
Umbra 不自带模型。译文来自你配置的 OpenAI 兼容接口，密钥在你这边。
现在能从 Chrome 商店安装吗？
1.0.0 已提交审核，商店页面还没有公开地址。当前从源码构建，再加载 dist。
扩展免费吗？
扩展本身免费，以 MIT 许可证开源。调用模型的费用由你的接口服务商收取。
作者能看到我翻译的内容吗？
不能。请求从浏览器直接发到你填写的接口，不经过 Umbra 的服务器。
支持哪些浏览器？
Chrome 与 Edge 的 Manifest V3。开发和构建需要 Node.js 18 或更高版本。
支持哪些接口？
内置常用接口预设，也可填写自定义 Base URL。

数据处理的完整说明见隐私政策。
