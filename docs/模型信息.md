### OpenRouter

格式是 `厂商/模型`：


| 代号                                                         | 说明                |
| ---------------------------------------------------------- | ----------------- |
| `openai/gpt-6-astra`                                       | OpenAI 最强         |
| `openai/gpt-6-sol`                                         | OpenAI Sol        |
| `openai/gpt-6-luna`                                        | OpenAI Luna       |
| `google/gemini-3.8-flash`                                  | Gemini 主力         |
| `deepseek/deepseek-v4.1-flash` 或 `deepseek/deepseek-flash` | DeepSeek 最新 Flash |


同平台常用：

- `z-ai/glm-5.3`
- `z-ai/glm-5.3-flash`
- `moonshotai/kimi-k3`
- `qwen/qwen3.8-max`
- 滚动别名：`~openai/gpt-luna-latest`、`~z-ai/glm-latest`、`~z-ai/glm-flash-latest`

OpenRouter 的 DeepSeek / Qwen slug 偶尔会有细微写法差异，以控制台 `/models` 列表为准。
