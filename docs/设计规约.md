# 设计规约

后续界面沿用这里的两套控件。不要另写一套动画或另一套布尔开关。

运动曲线只有一条：`--wt-spring`（`cubic-bezier(0.34, 1.56, 0.64, 1)`），时长 `--wt-spring-duration`（0.48s）。胶囊滑块行程短，拇指用同一条曲线、0.32s。`prefers-reduced-motion: reduce` 时这些过渡全部关掉。

## 单选列表

用在「一组里只能选一项」的列表，例如设置导航、提供商列表。弹簧只发生在列表内部：高亮从当前项滑到下一项，勾选在新项上弹入。旁边的内容区直接切换，不加这段动画。

结构：

- 容器是定位包含块（`position: relative`，已经 `sticky` 的不用再改），并加上 `wt-select-list`。
- 每一项是 `wt-select-item`。选中项再加 `is-selected`。未选中项可以有自己的 hover 底色；选中项的底和边框必须透明，颜色交给高亮块。
- 项内文字在左，最后放一个 `wt-check`（勾选 SVG）。用 `makeSelectCheck()` 生成。
- 高亮块由 `placeSelectIndicator(list, active, animate)` 放进容器。用户切换时 `animate` 为 `true`；首屏和尺寸变化为 `false`，直接落位。尺寸变化用 `watchSelectIndicator(list, activeSelector)`，不要在弹簧进行中把高亮拽回终点。

```ts
import {
  makeSelectCheck,
  placeSelectIndicator,
  watchSelectIndicator,
} from '../shared/selectList';
```

实现在 `src/shared/theme.css` 和 `src/shared/selectList.ts`。

## 胶囊滑块

布尔设置用胶囊滑块，不用浏览器自带的方框勾选，也不用单选圆点。

```html
<label class="switch-row">
  <span class="field-label">流式输出</span>
  <span class="wt-switch">
    <input type="checkbox" role="switch" />
  </span>
</label>
```

外壳是轨道，里面仍是原生 checkbox：读和写都用 `.checked`。关是砂色轨道，开是品牌色轨道，白色圆点滑到右侧。圆点画在外壳上，不要画在 `input` 的 `::after` 上。样式在 `src/shared/theme.css` 的 `.wt-switch`。
